# EEG Seizure Detection

A binary classifier that detects seizure activity from 1-second EEG segments, built on the
UCI Epileptic Seizure Recognition dataset (Andrzejak et al., 2001).

Model: Random Forest — 96.5% accuracy, 0.996 ROC AUC on held-out test data.

Built by Mahima Prajapati. Not a diagnostic tool — a learning/portfolio project.
